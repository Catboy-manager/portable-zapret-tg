Важно
Для winws/WinDivert и службы Windows запускайте приложение от имени администратора.

Управление обходом

Discord, YouTube, Telegram. Все профили general*.bat и все списки lists/* из runtime.

Порядок работы
  1. Запустите приложение от имени администратора: появится UAC. Без прав недоступны winws/WinDivert и служба.
  2. Выберите режим: «Пользователь» — обычный процесс, «Служба» — установка и запуск через service.bat.
  3. Выберите профиль general*.bat и нажмите «Применить профиль» — ручной выбор имеет приоритет.
  4. «Проверить сейчас» — тихая проверка текущих целей. «Проверить все профили» — полная матрица всех профилей.
  5. «Авто-подбор» — разовая смена на лучший профиль. Если голос Discord активен, автоматическая смена откладывается. «Ручной lock» фиксирует текущий выбор.
  6. Если критическая цель не проходит ни на одном профиле, появится уведомление «все таргеты провалены, провайдер заблокировал все методы обхода», в логе будет «Повторяю полный подбор» и полный подбор повторится один раз; победитель не применяется, пока цель заблокирована.
  7. В карточке Telegram нажмите «Запустить TG», затем «Сохранить TG» — ссылка для t.me появится ниже.
  8. «Проверить обновления» сверяет версию с GitHub Releases, «Скачать обновление» проверяет SHA-256 архива, «Установить и перезапустить» меняет файлы. Папки config/, history/ и logs/ сохраняются.
  9. При проблеме откройте «Логи» или «Экспорт диагностики» — записи обезличены.
Кнопки
Обновить
Перечитать состояние и настройки без перезапуска bypass.
Экспорт диагностики
Выгрузить историю и телеметрию без секретов и тел пакетов.
Проверить сейчас
Тихий зонд health-целей текущим профилем; успех только при HTTP 2xx.
Применить профиль
Вручную запустить выбранный профиль; перекрывает автоматический выбор.
Остановить bypass
Остановить winws и, если включён, режим службы.
Установить/запустить службу
Создать службу Windows с выбранным профилем и сразу её запустить.
Удалить службу
Удалить созданную службу и вернуть управление пользовательскому процессу.
Авто-подбор
Однократно выбрать лучший профиль. Пассивный подбор берёт порядок из таблицы «Профили и результаты тестов»: сначала критические цели, затем остальные 2xx и свежесть. При голосе Discord откладывается.
Ручной lock
Запретить автоматическую смену профиля, пока lock включён.
Запустить / Остановить / Сохранить TG
Управлять внешним TgWsProxy и сохранить его настройки.
Сохранить мониторинг
Применить интервал, тайм-аут, порог фейлов и cooldown тихих проверок.
Проверить все профили
Прогнать все профили последовательно: победитель применяется только в конце; при голосе Discord прогон не стартует. Настройки проверки фиксируются на время прогона, а при блокировке всех критических целей выполняется один повтор.
Отмена
Остановить полный прогон. Отменённый прогон не применяет победителя и не меняет сохранённый профиль.
Профили с ошибкой запуска
Отмечаются ⚠ в матрице и исключаются из авто-подбора; ручной выбор профиля остаётся доступным.
Проверить обновления / Скачать / Установить
Сверка с GitHub Releases, загрузка ZIP с обязательной проверкой SHA-256 и установка отдельным помощником. Приложение перезапустится, а config/, history/ и logs/ останутся на месте.
Обновить матрицу / ленту / логи
Перечитать таблицу результатов, ленту событий и лог приложения.
Фильтры «Все / Цели / Профили / События»
Сузить ленту диагностики до нужного типа записей.

Быстрое действие
Пользовательский режим запускает winws как процесс. Служба использует логику service.bat (sc create/start, реестр стратегии).
