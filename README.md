# Portable Zapret + TgWsProxy Controller

Портативное десктоп-приложение (Electron) для Windows, объединяющее обход из набора **zapret-discord-youtube** (`bin/winws.exe` + WinDivert, профили `general*.bat`, списки `lists/*`) и внешний **TgWsProxy_windows.exe** (локальный MTProto `127.0.0.1:1080`).

## Что делает
- Управляет `winws.exe` в **пользовательском режиме** или как **служба Windows** (логика аналогична `service.bat`: разбор выбранного `general*.bat` → аргументы winws → `sc create/start`, запись стратегии в реестр службы).
- Запускает/останавливает `TgWsProxy_windows.exe` как внешний процесс и показывает локальный endpoint/ссылку `t.me/proxy?...`.
- **Тихий мониторинг** (лёгкие HTTP/TLS-пробы целей Discord/YouTube/Google, без остановки winws) и **редкое автопереключение** при устойчивой деградации: пробует 2–3 лучших кандидата, быстрый откат, cooldown. Полный разрывающий прогон `test zapret.ps1` не используется.
- Хранит **настройки, историю проверок и логи** внутри этой папки (`config/`, `history/`, `logs/`) — портативно.

## Структура
- `runtime/` — копия нужных компонентов: `bin/`, `lists/` (все general/google/ipset, user и exclude), все `general*.bat`, `service.bat` (референс), `TgWsProxy_windows.exe`, `utils/targets.txt`.
- `app/` — Electron-приложение (UI + логика оркестрации/мониторинга).
- `config/`, `history/`, `logs/` — состояние, статистика, логи.

## Требования
- Windows 10/11 x64.
- Права **Администратора** нужны для работы `winws/WinDivert` и тем более для установки/управления службой.
- Установленный **Node.js + npm** (для `npm install` и запуска; проверено наличие node/npm в системе).

## Запуск (из папки `app/`)
```bat
cd app
npm install
npm start
```
Для операций со службой и драйвером запускайте терминал/приложение **от имени администратора**.

## Замечания
- Смена профиля/метода = перезапуск winws, поэтому возможен **короткий блик** обхода на фильтруемых соединениях в момент редкого переключения (мониторинг сам winws не перезапускает). Прямой интернет вне фильтров winws не затрагивается.
- `TgWsProxy_windows.exe` управляется как внешний процесс (чёрный ящик). В UI можно хранить/отображать host/port/secret ссылки; фактическая конфигурация прокси определяется самим exe.
- Все существующие `.bat` в корне исходной папки не изменялись — приложение работает из `portable-zapret-tg/`.

## Настройки тихого контроля
Интервал, таймаут, порог деградации, число кандидатов, cooldown, автопереключение/автовыбор/автозапуск Tg — настраиваются в UI и сохраняются в `config/settings.json`. История и статистика — в `history/`.
